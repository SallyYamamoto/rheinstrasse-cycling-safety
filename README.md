# Rheinstrasse: publication candidate

This folder is a curated GitHub Pages site. Set `index.html` as the entry point. **Do not publish it until the rights and token checks below are complete.** The current token string is intentionally a placeholder; the scene will stop with a visible notice until it is configured.

## Build and verify

The release was built from the original project at `D:\Desktop\Oct_3D GIS\Rheinstr`. The private build helper extracts the verified one-check-per-frame POV module from `index-pov-test.html`, uses the current `index-safety-guide.html` UI, and copies the runtime files, including `parked-cars.js` and the author's published parking footprints. It strips the unused `image_name` fields from the release copy. The helper and the Japanese publication notes are kept outside this published folder.

Create an application token in [Cesium ion](https://cesium.com/learn/ion/cesium-ion-access-tokens/) with only `assets:read`, select necessary ion asset IDs (currently 6023901, 6026374 and 6026396, plus the actual World Terrain and default imagery assets shown in the network inspector), and restrict Allowed URLs to your final HTTPS Pages address. Local testing may need a separate localhost token or temporarily permitted localhost URL. Replace `REPLACE_WITH_RESTRICTED_READ_ONLY_TOKEN` in `index.html`. **A browser token is public by design**; limits and URL restrictions constrain its use. Never commit a private `assets:write`, `tokens:write` or default all-assets token. Rotate the previous default token if its exposure was unintended, after confirming other apps will not break.

To publish, create a clean GitHub repository from the *contents of this folder only*, review its staged file list, and configure Settings → Pages → Deploy from branch → `main` / root. Publishing is on hold until the asset-rights checks below are cleared. Pages is public even if its repository is private. `.nojekyll` is present. Test all three behaviors after deploying: observed traffic playback, intersection scenario, and POV with radar and scheduled occlusion.

Confirm the intended public use is noncommercial.
- Active bicycle rider: `models/Meshy_Red_Rider_colored.glb`, generated and recolored by the project author using Meshy. The previous `chad_rider.glb` (a Sketchfab asset) is excluded. The release config uses the new model's measured 1.900052 m longitudinal dimension and offsets its centered origin upward by 0.870482 m before scaling. Check the visual heading and ground contact in the published viewer. [Meshy explains](https://help.meshy.ai/en/articles/10137554-what-is-the-ownership-of-the-generated-models) that a Free-plan generation is CC BY 4.0 and requests Meshy credit; paid-plan ownership differs. Check the plan used when generating this asset, and add the CC BY 4.0 licence link in the viewer if it was Free-plan generated. The tool is credited in the viewer either way.
- `models/tree-placeholder.glb` and `models/bush.glb` contain four PNG images **inside each GLB** as leaf/bark material textures; no separate PNG files are necessary. The generated geometry can be attributed to [EZ-Tree](https://github.com/dgreenheck/ez-tree), © 2024 Daniel Greenheck, [MIT software license](https://github.com/dgreenheck/ez-tree/blob/main/LICENSE); the full MIT notice is copied into `THIRD_PARTY_NOTICES.md`. - Accident data: `GeoJSON/Accident_statistics.geojson` derives from [Unfallatlas (2016–2025)](https://www.statistikportal.de/de/karten/unfallatlas). Source note: **© Statistische Ämter des Bundes und der Länder; Unfallatlas; [Datenlizenz Deutschland – Namensnennung – Version 2.0 (dl-de/by-2-0)](https://www.govdata.de/dl-de/by-2-0)**. For this viewer the accident data was geographically filtered, joined with intersection information and converted to GeoJSON. The public viewer displays this source note and marks the modifications. - CityGML 3D tiles, roads and markings on ion (6023901, 6026374, 6026396): confirm permission to provide public visual access, separately from ion access settings. `rheinstrasse_vegetation.json`, `rheinstrasse_road_samples.json`, `GeoJSON/Target_intersections.geojson` and `conflict_scenarios.json` also expose coordinates and should be reviewed for source ownership. - Parked-car footprints: `GeoJSON/parked_vehicles.geojson` is the project author's processed analysis output, generated using DLR inputs, and is included at the author's direction. The 230 features are publicly downloadable as model placements; the DLR source imagery and working files are not part of the release. `parked-cars.js` uses these footprints to place 3D cars. Publication of derived geometries should follow the underlying source agreement; this repository makes no assertion about ownership of the DLR inputs.
